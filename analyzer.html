2. Select a Window

Select a window: drag across the graph; drag its edges to adjust. Move your cursor over the graph (or touch it) to read the time and the X, Y and Z values at that point.

The time and values at your cursor appear here.

A low-pass filter keeps movement below the cutoff frequency and removes everything above it, such as sensor noise or vibrations. A high-pass filter removes anything below the cutoff, such as a slow drift, and keeps everything above it.

8. Overlay repetitions

Use this section to compare multiple trials of the same task (visually). Load each trial above and then select the data series to add to the window below. You can select the offset to remove and add a label for each repetition. Sample data of 5 vertical jumps is also provided. The maximum number of trials to compare is 12.

Lastly, you can select whether to compare the trials using absolute seconds (which will show differences in how long each trial took) or as time normalized (which will show the trials using 0 to 100% of the movement time). You can line up the trials using the start of the trial or highest point. (hint: it may be helpful to use the window above to select a consistent starting point for each trial)

The example is simulated data: five vertical jumps that differ a little in height, timing and noise. It loads the trial into section 2 and adds each jump here.

Time axis

“Time normalized” stretches every repetition to the same length, so repetitions of different durations can be compared by shape. Seconds keeps the real timing. The average is worked out only where every repetition has data.
